	\section*{Logistical Prerequisites}
	
	\subsection*{Task 1: Install MakeCode Arcade (Offline)}
	Due to intermittent network connectivity during class sessions, every student must install the \textbf{standalone offline version} of Microsoft MakeCode Arcade on their personal device.
	
	\textbf{Reference:} \url{https://arcade.makecode.com/offline-app}
	
	\textbf{Procedure:}
	\begin{enumerate}
		\item Navigate to \url{https://arcade.makecode.com/offline-app}.
		\item Review and accept the Microsoft Software License Terms.
		\item Download the appropriate installer for your operating system:
		\begin{itemize}
			\item Windows: \texttt{makecode-arcade-setup-win64.exe}
			\item macOS: \texttt{makecode-arcade-setup-mac.dmg}
		\end{itemize}
		\item Execute the installer and follow the on-screen prompts.
		\item Launch the application to confirm it runs without an active internet connection.
	\end{enumerate}
	
	\noindent\textit{Note: The offline app is a full-featured standalone editor. Once installed, you may create, edit, and download projects without network access.}
	
	\subsection*{Task 2: Create Your MakeCode Arcade Account}
	Create a user account on the MakeCode Arcade platform. You must register using your institutional \textbf{Heuser EDU} email address. This account will be used to save and sync your projects.
	
	\section*{Programming Assignment}
	
	Build a program in MakeCode Arcade that satisfies the following behavioural specification:
	
	\begin{itemize}[leftmargin=*]
		\item The program must display a \textbf{score} on the screen.
		\item When the user presses the \textbf{A button}, the score must \textbf{increase}.
		\item When the user presses the \textbf{B button}, the score must \textbf{decrease}.
		\item When the user presses any button on the \textbf{keypad (directional pad)}, the background colour must \textbf{change}. Each directional button must produce a \textbf{distinct} colour.
	\end{itemize}
	
	\noindent\textbf{Constraints \& Expectations:}
	\begin{itemize}
		\item Do not submit a step-by-step tutorial. Submit a \textbf{working program file} (\texttt{.png} or project link).
		\item You must infer the necessary components, decompose the problem, and assemble the logic independently.
		\item The solution must be robust: buttons should respond correctly and the score must remain visible at all times.
	\end{itemize}
