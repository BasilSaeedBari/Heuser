\sectionhead{1. The Mission}
In class you learned that tokens are our currency, and that the smart way to spend them is
\textbf{plan smart, build cheap, start fresh}. Now you will prove it.
Your job: build \textbf{one small interactive program} that runs in a web browser, using the
\textbf{5-step prompt process} from the lecture:
\begin{center}
\textbf{Core Logic} $\rightarrow$ \textbf{Visual Vibe} $\rightarrow$ \textbf{Sensory Feedback} $\rightarrow$ \textbf{State \& Storage} $\rightarrow$ \textbf{Debugging}
\end{center}

\sectionhead{2. Pick Your Project}
Choose \textbf{one}. Keep it small. A finished simple project beats a broken ambitious one.
\begin{itemize}
  \item \textbf{A. Catch Game:} Things fall from the top. The player moves something to catch the good ones and dodge the bad ones.
  \item \textbf{B. Virtual Pet:} A creature on screen that gets hungry, happy, or sleepy, and reacts to what the player does.
  \item \textbf{C. Pattern Memory:} The game shows a growing sequence of colors or shapes. The player must repeat it.
\end{itemize}

\sectionhead{3. The Hard Rules}
\begin{warnbox}
\begin{itemize}
  \item \textbf{No assets.} No image files, sound files, downloaded fonts, or libraries. Everything must be created by \emph{code}: CSS shapes, inline SVG, or drawing on a \texttt{\textless canvas\textgreater}.
  \item Sound is allowed \emph{only} if the code generates it (for example, the Web Audio API).
  \item Your final program is exactly \textbf{three code files}: one HTML, one CSS, one JavaScript.
  \item It must work by double-clicking the HTML file, with no internet.
\end{itemize}
\end{warnbox}

\sectionhead{4. The Process: Repeat This Loop for All 5 Stages}
\begin{enumerate}[label=\textbf{Step \Alph*.},leftmargin=3.6em,itemsep=3pt]
  \item \textbf{Architect.} Open a \textbf{new agent} with your smartest, highest-reasoning model. Ask it for a long, detailed plan for \emph{this stage only}. Save the plan.
  \item \textbf{Builder.} Open \textbf{another new agent} with a faster, cheaper model. Give it your plan and your current code. It builds \emph{only} this stage.
  \item \textbf{Test.} Open the page in your browser. Check the ``Done when'' column below. If it fails, fix it before moving on.
\end{enumerate}
Then move to the next stage with \textbf{fresh agents again}. Never reuse a cluttered agent across stages.

\begin{infobox}
\textbf{Tips.} (1) Do not paste all five stages into one giant request. That breaks Golden Rule 1.
(2) If an agent starts forgetting things or making things up, its context window is full. Start a fresh one.
(3) Test after \emph{every} stage, not just at the end.
(4) Keep your tokens in mind: share only the files and plan the agent needs.
\end{infobox}
