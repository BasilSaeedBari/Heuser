\section*{Goal}
Put your Homework 6 website online under your own GitHub account, organized in the exact folder structure below.

\begin{term}{Key words you must know}
\textbf{Git:} version control software on your computer that records every change to your files.\\
\textbf{GitHub:} a website that stores Git projects online so you can share and publish them.\\
\textbf{Repository (repo):} a project folder tracked by Git, holding your files and their full history.\\
\textbf{Commit:} a saved set of changes with a short message describing them.\\
\textbf{GitHub Pages:} free hosting that turns a repository of static files into a live website.
\end{term}

\section*{Part 1: Account}
\begin{enumerate}[leftmargin=*]
\item Create a GitHub account using your \textbf{personal email address}. Choose a professional username, since it will appear in your links.
\item Verify the email address from the message GitHub sends you.
\item In \textit{Settings $\rightarrow$ Emails}, add your \textbf{Heuser EDU email} to the same account and verify it too. Both emails must now appear as verified.
\end{enumerate}

\section*{Part 2: Repository}
\begin{enumerate}[leftmargin=*,resume]
\item Create a new \textbf{public} repository named exactly \texttt{Heuser}.
\item Upload your files so that the structure is exactly:
\end{enumerate}

\section*{Part 3: Publish (needed for Homework 8)}
Homework 8 must link to this website, so turn on GitHub Pages as shown in class.
\begin{enumerate}[leftmargin=*,resume]
\item In the repo, open \textit{Settings $\rightarrow$ Pages}.
\item Deploy from the \texttt{main} branch, root folder, and save.
\item Wait a minute, then open your link, which looks like:\\
\texttt{https://YOUR-USERNAME.github.io/Heuser/CS\_CRP/Homework\_6/}
\end{enumerate}
\textbf{Check:} the page must load with its styling and script working. If it looks plain, check that the file names match what \texttt{index.html} links to.
